## Learned memory

None — Amazon Q CLI has no built-in auto/learned memory for conventions and no memories directory; the only persistent stores are the opt-in beta knowledge base (`q settings chat.enableKnowledge true`, then `/knowledge add --name ... --path ...`, kept under ~/.aws/amazonq/knowledge_bases) and the user-managed legacy global_context.json/profiles, which are read only once by migration, not as learned memory.

## Compatibility notes

Compatibility: reads AGENTS.md (cross-tool convention) plus AmazonQ.md and README.md as auto-context; does NOT read CLAUDE.md, GEMINI.md, CRUSH.md, .cursorrules, opencode.json or kilo.jsonc — zero references anywhere in the repo. skill_dirs is empty: whole-repo grep for "skill" returns 0 hits, and paths.rs enumerates every convention dir (workspace: .amazonq/cli-agents, .amazonq/prompts, .amazonq/mcp.json, .amazonq/cli-todo-lists, .amazonq/.subagents, .amazonq/rules; global: .aws/amazonq/cli-agents, .aws/amazonq/prompts, .aws/amazonq/mcp.json, .aws/amazonq/cli-checkouts, .aws/amazonq/global_context.json, .aws/amazonq/profiles, .aws/amazonq/knowledge_bases, plus data_local_dir()/amazon-q/settings.json for `q settings`) with no skills directory — evidence: https://raw.githubusercontent.com/aws/amazon-q-developer-cli/main/crates/chat-cli/src/util/paths.rs and https://api.github.com/repos/aws/amazon-q-developer-cli/git/trees/main?recursive=1. Resource mechanics: only the file:// scheme is supported in `resources`; relative paths resolve against cwd, ~/$VAR expanded, globs supported, missing files skipped silently, per-file cap 10 KiB, all collected resources + agent `prompt` + spawn hooks injected as a fake user/assistant context-message pair at conversation start (create_context_messages) — https://raw.githubusercontent.com/aws/amazon-q-developer-cli/main/crates/agent/src/agent/mod.rs. .amazonq/.subagents holds delegate-tool subagent session state, not instructions. Project-rule concept per AWS docs: https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/context-project-rules.md. IMPORTANT: repo is archived — README says \"no longer being actively maintained... Amazon Q Developer CLI is now available as Kiro CLI (closed source)\" (https://raw.githubusercontent.com/aws/amazon-q-developer-cli/main/README.md) and the AWS CLI doc page now redirects to kiro.dev/docs/cli (https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/command-line.md), so Kiro CLI's convention loading may differ from what is documented here.
