## Learned memory

OpenHands has no always-on auto-memory: durable memory is an opt-in, default-off two-tier feature where the agent maintains MEMORY.md indexes at ~/.openhands/memory/ (user tier) and <workspace>/.openhands/memory/ (project tier) which are injected into the system prompt as <MEMORY_CONTEXT> only when AgentContext(load_memory=True) is set — otherwise the default guidance is to keep repo knowledge in AGENTS.md (the Context Condenser only compacts in-conversation history, it does not persist across conversations).

[src](https://docs.openhands.dev/sdk/guides/persistent-memory.md)

## Compatibility notes

Compatibility: OpenHands natively reads other vendors' repo-root files — AGENTS.md, CLAUDE.md, GEMINI.md, .cursorrules, AGENT.md/singular — all loaded simultaneously under distinct skill names ('agents', 'claude', 'gemini', 'cursorrules'), so they do not override each other; matching is case-insensitive and symlinked aliases are deduped. It implements the Agent Skills spec (agentskills.io) as a superset, adding keyword triggers and path-triggered rules; docs explicitly compare path rules to Claude Code 'rules' and hooks to .claude/settings.json (location differs: .openhands/hooks.json). Legacy OpenHands formats keep working and load unchanged: .openhands/skills/ and .openhands/microagents/ (repo + user ~/.openhands variants) and trigger-less .md files that inject full content every turn; docs steer users to .agents/skills/ and AGENTS.md for new content. Documented precedence (docs + source): project skills > user skills > public registry skills; within a scope .agents/skills/ > .openhands/skills/ > .openhands/microagents/ (first-wins dedup by skill name); conversation workspace > git repo root; explicitly supplied SDK Skill objects > auto-loaded; installed skills lowest. No home-directory AGENTS.md is read — third-party instruction files are only searched in the workspace and git repo root; user-wide sharing goes through ~/.agents/skills/ or org repos. SDK loader flags all default false (load_user_skills, load_public_skills, load_project_skills, load_memory); product surfaces enable them (CLI/headless/dev-mode auto-loads ~/.agents/skills; Agent Canvas manages skills via Customize > Skills; Cloud imports skills from Git). The ~/.openhands base dir is relocatable via the OH_PERSISTENCE_DIR env var. Repo-level non-instruction conventions it reads: .openhands/setup.sh (executed each session), .openhands/hooks.json + .openhands/hooks/ scripts (context injection, stop gates), legacy .openhands/pre-commit.sh.
