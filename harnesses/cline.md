## Learned memory

No built-in learned/auto memory — Cline has no memories store or auto-write memory dir; the documented "Memory Bank" is a user-implemented methodology (structured markdown files committed in the repo, activated by a .clinerules file carrying custom instructions), and cross-session continuity otherwise relies on task history/checkpoints plus Auto Compact for context management.

## Compatibility notes

Compatibility: Cline reads three other vendors' files — Cursor (.cursorrules and .cursor/rules/**/*.mdc), Windsurf (.windsurfrules), and the AGENTS.md standard (workspace AGENTS.md + global ~/.agents/AGENTS.md) — and it reads Claude Code's project skills dir .claude/skills, but NOT Claude Code's CLAUDE.md (no .claude/skills-global ~/.claude/skills either) and NOT GEMINI.md/CRUSH.md/.github/copilot-instructions.md/opencode.json/kilo.jsonc (docs rule-types table lists only Cline Rules, Cursor Rules, Windsurf Rules, AGENTS.md; repo-wide grep of apps/vscode/src, sdk/packages, apps/cli/src for those names found only provider/model-id references). Own-format notes: both .clinerules/ (legacy) and .cline/rules/ (current) are deliberately honored by every surface (cline/cline#14186); .clinerules/{workflows,hooks,skills} subdirectories are excluded from rule scanning (CLINERULES_EXCLUDED_SUBDIRECTORIES); workflows live in .clinerules/workflows + ~/Documents/Cline/Workflows + ~/.cline/workflows with the same project/global layout. Skills are progressive-loading (name+description ~100 tokens always; SKILL.md on trigger via use_skill or /slash command; bundled docs/scripts on demand), enabled state stored in SKILL.md `disabled` frontmatter. Skill collision precedence: docs say global > project; source getAvailableSkills iterates backwards so org/remote-config skills > global (~/.cline/skills, ~/.agents/skills) > project. Enterprise remote config can also inject org rules/workflows (materialized to disk) and remote skill lists. The CLI's `cline skill` command is only a wrapper around the external npm `skills` CLI invoked with `--agent cline`.
